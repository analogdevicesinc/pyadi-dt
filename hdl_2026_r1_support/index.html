    HDL 2026.1 design support

    Every Xilinx project/carrier pair in the HDL 2026.1.0 release (commit b62abeff22d6), and how far the XSA pipeline supports it. Reference device trees are from Linux commit b486fe824008; XSAs are from the Kuiper 2026_r1 boot partition.

    Validated

    The release XSA selects a profile on its own, the generated tree compiles and lints clean, and it matches the kernel reference tree (ADI driver bindings for declarative profiles, driver roles for the hand-written builders). Checked by test/xsa/test_hdl_release_coverage.py.

    Profile, not validated

    A profile exists, but the release ships no XSA to check it against.

    Profile only

    A profile exists without a builder for the design’s devices.

    Not supported

    No profile; the reason column says which input is missing, if any.

    17 profile, not validated, 62 validated of 79 designs.
